#  AI Career Assistant

An AI-powered Career Assistant built with Python and Streamlit to help students and job seekers with resume analysis, interview preparation, job recommendations, and career development.

##  Features

-  Resume Analysis
-  Resume-based Career Guidance
-  Job Recommendations
-  Mock Interview Preparation
-  Technical Interview Questions
-  Behavioral Interview Preparation
-  Career Development Support
-  AI-powered responses using Google Gemini
-  Report generation and download

##  Technologies Used

- Python
- Streamlit
- Google Gemini API
- PyPDF2
- ReportLab
